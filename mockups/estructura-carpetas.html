🖥️ Presentación pages · components

Todo lo visible. pages/ = pantallas; components/ = piezas que se reusan. El corazón es brain/modules/: los 17 módulos del cliente.

🧠 Estado & lógica store · hooks · types

store/ guarda el estado vivo. hooks/ lógica reutilizable. types/ define qué es cada dato. Sin backend aquí — solo memoria.

🔌 Servicios services/

La única puerta al exterior. Datos (Supabase), IA (Claude), Agente PM y generación de PDF. Ningún componente salta esta capa.

🛢️ Backend supabase/

18 tablas en Postgres. Cada cambio de esquema = una migración numerada. RLS controla permisos. Los seeds cargan datos reales.

🤖 IA api/claude.ts

Única función de servidor. Esconde la API key y reenvía a Anthropic. La usan claudeApi + el Agente PM.

Regla de oro del flujo

componente→ store→ service→ Supabase→ UI

Los datos siempre viajan por este carril. Si entiendes una función, entiendes todas.
