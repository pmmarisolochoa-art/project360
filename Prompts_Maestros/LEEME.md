# Prompts Maestros — [NOMBRE]

Kickoffs reutilizables: textos que se copian y pegan al abrir la terminal para arrancar un tipo de trabajo recurrente.

**Patrón de un buen prompt maestro:**
1. Rol + qué archivos leer antes de responder (`CLAUDE.md`, `Contexto.md`, lo relevante)
2. Objetivo + dónde pegar la info nueva `[...]`
3. El proceso en pasos numerados (qué entrega)
4. Reglas (no inventar, registrar decisiones, idioma)

Crea uno por cada tarea que se repita 3+ veces.
